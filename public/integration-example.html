🌧️ Emoji Rain - Integration Example

This page demonstrates the standalone Emoji Rain widget in action. Notice how the emoji rain respects z-index layering with the modal!

💡 Current Setup:
  • Container Z-Index: 10
  • Modal Z-Index: 999
  • Result: Emojis appear behind the modal

Try It Out:

Installation Code:

<!-- Add this to your HTML --> <script src="https://cdn.jsdelivr.net/gh/yourusername/emoji-rain-parallax@latest/dist/widget.min.js"></script> <script> const rain = EmojiRain.init({ emojis: ['🌟', '💫', '✨', '🎉', '🎊', '⭐', '🌈'], containerZIndex: 10, showControls: false, autoPlay: false }); </script>

Programmatic Control:

// Trigger rain manually rain.triggerRain(); // Drop single emoji rain.dropSingleEmoji(); // Clear all emojis rain.clearEmojis(); // Clean up (removes container and controls) rain.destroy();

Z-Index Examples:

  • Behind modals: containerZIndex: 10
  • Above most content: containerZIndex: 100
  • Above everything: containerZIndex: 9999

🎭 Modal Example

Notice how the emoji rain appears behind this modal because the modal has a higher z-index (999) than the container (10).

To make emojis appear on top of modals, increase the containerZIndex value.
